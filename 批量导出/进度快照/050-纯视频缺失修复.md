## 具体修改的代码前后对比

### 片段时长裁剪

修改前：

```js
endFrame: sourceEndFrame,
```

修改后：

```js
const appendEndFrame =
  timelineDurationFrames !== null && sourceDurationFrames > timelineDurationFrames
    ? sourceStartFrame + Math.max(timelineDurationFrames - 1, 0)
    : sourceEndFrame;
```

### 补追加对象

修改前：

```js
const missingAudioRecords = selectSupplementalAudioRecords(...);
supplementalResult = appendSupplementalAudioRecords(mediaPool, missingAudioRecords);
```

修改后：

```js
const missingSupplementalRecords = selectSupplementalTimelineRecords(...);
supplementalResult = appendSupplementalTimelineRecords(mediaPool, missingSupplementalRecords);
```

### 补追加方式

修改前：

```js
mediaPool.AppendToTimeline(clipInfos)
```

修改后：

```js
for (const record of records) {
  mediaPool.AppendToTimeline([record.clipInfo]);
}
```
