## 具体修改的代码前后对比

### `plugin-runtime/preload.js`

修改前主转换链路：

```js
const aafResult = tryImportTimelineViaAaf(...);

if (!createdTimeline) {
  const duplicateResult = tryDuplicateTimelineWithFrameRate(...);
}

if (!createdTimeline) {
  const drtResult = tryImportTimelineFromDrt(...);
}
```

修改后主转换链路：

```js
const directCopyResult = copyTimelineContentsDirectly(
  project,
  mediaPool,
  sourceTimeline,
  targetFolderResult.folder,
  targetName,
  targetFrameRate
);
```

修改前 AAF/DRT 依赖导出文件：

```js
timeline.Export(filePath, candidate.exportType, candidate.exportSubtype);
createdTimeline.ImportIntoTimeline(aafPath, importOptions);
mediaPool.ImportTimelineFromFile(drtPath);
```

修改后直接创建和追加：

```js
project.SetSetting("timelineFrameRate", String(targetFrameRate));
mediaPool.CreateEmptyTimeline(targetName);
mediaPool.AppendToTimeline(sourceContent.clipInfos);
```

新增源时间线内容收集：

```js
const sourceStartFrame = toFiniteFrameNumber(item.GetSourceStartFrame());
const sourceEndFrame = toFiniteFrameNumber(item.GetSourceEndFrame());
const recordFrame = toFiniteFrameNumber(item.GetStart(true));

clipInfo = {
  mediaPoolItem,
  startFrame: sourceStartFrame,
  endFrame: sourceEndFrame,
  mediaType: trackConfig.mediaType,
  trackIndex,
  recordFrame
};
```
