## 具体修改的代码前后对比

### 1. 策略类型扩展

修改前：

```ts
export type FrameRateConversionStrategy = "resolve-render" | "ffmpeg-cfr" | "ffmpeg-motion";
```

修改后：

```ts
export type FrameRateConversionStrategy = "resolve-render" | "ffmpeg-cfr" | "ffmpeg-motion" | "resolve-ui-copy-paste";
```

### 2. 策略归一化扩展

修改前：

```ts
return value === "ffmpeg-cfr" || value === "ffmpeg-motion" || value === "resolve-render"
  ? value
  : defaultFrameRateConversionStrategy;
```

修改后：

```ts
return value === "ffmpeg-cfr" ||
  value === "ffmpeg-motion" ||
  value === "resolve-render" ||
  value === "resolve-ui-copy-paste"
  ? value
  : defaultFrameRateConversionStrategy;
```

### 3. 单元测试补充

新增：

```ts
expect(normalizeFrameRateConversionStrategy("resolve-ui-copy-paste")).toBe("resolve-ui-copy-paste");
```
