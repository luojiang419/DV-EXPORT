## 具体修改的代码前后对比

### 1. 独立导出结果面板移入底部栏

修改前：

```tsx
<section className="panel panel--summary">
  ...
  <ExportSummary result={lastResult} isExporting={isExporting} />
</section>

<div className="fixed-export-action">
  {fixedActionDisabledReason ? (
    <div className="fixed-export-action__status">{fixedActionDisabledReason}</div>
  ) : null}
  <button ...>{fixedActionLabel}</button>
</div>
```

修改后：

```tsx
<div className="fixed-export-action">
  <div className="fixed-export-action__summary">
    <ExportSummary
      result={lastResult}
      isExporting={isExporting}
      statusMessage={fixedActionDisabledReason || "当前只启动本次创建的任务，不改动用户原有队列。"}
    />
  </div>
  <button ...>{fixedActionLabel}</button>
</div>
```

### 2. 底部栏高度

修改前：

```css
.fixed-export-action {
  width: min(360px, calc(100vw - 48px));
  display: grid;
  gap: 8px;
}
```

修改后：

```css
.fixed-export-action {
  left: 24px;
  right: 24px;
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(280px, 360px);
  gap: 18px;
  height: 52px;
}
```

### 3. 导出结果摘要

修改前：

```tsx
return (
  <div className="summary-panel">
    <div className="summary-panel__stats">...</div>
    <div className="summary-panel__list">...</div>
  </div>
);
```

修改后：

```tsx
return (
  <div className="summary-panel">
    <div className="summary-panel__title">导出结果</div>
    <div className="summary-panel__status" title={title}>
      {isExporting ? <span className="loading-spinner" /> : null}
      <span>{content}</span>
    </div>
  </div>
);
```
