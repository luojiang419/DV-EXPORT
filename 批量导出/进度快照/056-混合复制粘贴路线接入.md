# 056 混合复制粘贴路线接入

## 已完成内容

- 已完成模块 3：在 `plugin-runtime/preload.js` 接入 `resolve-ui-copy-paste` 混合路线
- 默认路线保持为 v0.1.20 内部 API 复制：
  - `copyTimelineContentsDirectly()`
  - `AppendToTimeline([{clipInfo}])`
- 新路线仅在 `strategy === "resolve-ui-copy-paste"` 时启用：
  - Resolve API 创建目标帧率空时间线
  - Resolve API 切换源时间线并打开 Edit 页
  - 主进程调用 AutoHotkey v2 执行 `Ctrl+A`、`Ctrl+C`
  - Resolve API 切换目标时间线
  - 主进程调用 AutoHotkey v2 执行 `Ctrl+V`
  - Resolve API 校验目标帧率和可校验项目数量
- 已修正异常边界：如果 AHK 未安装或执行失败，已创建的目标时间线会通过现有失败清理逻辑删除，不留下半成品。

## 当前修改模块

- `plugin-runtime/preload.js`

## 具体修改的代码前后对比

### 1. 运行时策略集合扩展

修改前：

```js
const frameRateConversionStrategies = new Set(["resolve-render", "ffmpeg-cfr", "ffmpeg-motion"]);
```

修改后：

```js
const uiCopyPasteFrameRateConversionStrategy = "resolve-ui-copy-paste";
const frameRateConversionStrategies = new Set([
  "resolve-render",
  "ffmpeg-cfr",
  "ffmpeg-motion",
  uiCopyPasteFrameRateConversionStrategy
]);
```

### 2. 新增 UI 复制粘贴路线

新增：

```js
async function copyTimelineContentsWithUiAutomation(...) {
  const createResult = createEmptyTimelineWithFrameRate(...);
  // 切源时间线，调用 AHK copy；切目标时间线，调用 AHK paste；再校验。
}
```

### 3. 单条转换流程改为可等待外部自动化

修改前：

```js
function convertOneTimelineFrameRate(args) {
  const directCopyResult = copyTimelineContentsDirectly(...);
}
```

修改后：

```js
async function convertOneTimelineFrameRate(args) {
  const directCopyResult =
    strategy === uiCopyPasteFrameRateConversionStrategy
      ? await copyTimelineContentsWithUiAutomation(...)
      : copyTimelineContentsDirectly(...);
}
```

### 4. 批量转换循环等待每条结果

修改前：

```js
results.push(convertOneTimelineFrameRate({ ... }));
```

修改后：

```js
results.push(await convertOneTimelineFrameRate({ ... }));
```
