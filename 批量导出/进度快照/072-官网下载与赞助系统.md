# 072 - 官网下载与赞助系统

## 任务目标

把 `G:\data\app\pond5_clip_manager\tools-web` 已有的下载与赞助思路迁移到 DV EXPORT 官网，并适配为可部署到自有服务器的完整功能；保留官网现有 Web Demo，让用户可以下载插件、扫码赞助、提交记录并查看公开赞助榜。

## 已完成内容

### 模块 1：方案审计与迁移边界

- 已审计原网站的二维码、表单、FastAPI、SQLite、人工确认和赞助榜流程。
- 只迁移功能模式与经用户授权的收款二维码，没有迁移 Pond5 品牌、联系方式和社群信息。
- 明确采用“用户自报 + 管理员人工核实”的流程，不伪装成支付平台自动回调。

### 模块 2：站内下载

- 已构建 `DV-EXPORT-v0.1.26-setup.exe`。
- 官网所有下载按钮已统一打开下载与赞助弹窗。
- 安装包和 SHA256 校验文件已复制进官网最终产物。
- 官网版本和文件名由根目录 `package.json` 自动派生，减少版本漂移。

### 模块 3：赞助弹窗

- 已加入微信、支付宝二维码和全屏预览。
- 已加入赞助记录提交表单、隐私提示、成功/失败状态。
- 已支持 `?support=1` 自动打开弹窗。
- 已补齐 Esc 分层关闭、关闭后焦点还原和页面滚动锁定。

### 模块 4：赞助榜与管理页

- 公开页：`sponsors.html`，只展示管理员确认过的记录。
- 管理页：`sponsors-admin.html`，支持待审核、已确认、已拒绝筛选和确认/拒绝操作。
- 管理令牌仅保存在浏览器 `sessionStorage`，管理页设置 `noindex,nofollow`。

### 模块 5：赞助后端

- 新增 `website-backend`，技术栈为 FastAPI + SQLite。
- API 前缀：`/api/dv-export-support/v1`。
- 支持记录提交、状态查询、公开列表、管理列表、确认和拒绝。
- 包含蜜罐字段、输入标准化、金额上限、IP 哈希、10 分钟 3 次限流和恒定时间令牌校验。
- Nginx 示例覆盖客户端传入的 `X-Forwarded-For`，避免通过伪造请求头绕过限流。

### 模块 6：构建与部署

- `npm run build:website`：校验安装包后构建官网、Web Demo 和全部下载资源。
- `npm run build:website:release`：先生成当前版本安装包，再构建官网。
- 新增 Nginx HTTPS/静态资源/API 代理示例。
- 新增 systemd 服务模板、后端环境变量示例和部署文档。
