## 具体修改的代码前后对比

### 1. 主进程窗口创建

修改前：

```js
function createWindow() {
  const window = new BrowserWindow({ ... });
  window.removeMenu();
  window.loadFile(path.join(pluginRoot, "index.html"));
}
```

修改后：

```js
let mainWindow = null;

function createWindow() {
  if (mainWindow && !mainWindow.isDestroyed()) {
    if (mainWindow.isMinimized()) {
      mainWindow.restore();
    }
    mainWindow.show();
    mainWindow.focus();
    return mainWindow;
  }

  mainWindow = new BrowserWindow({ ... });
  mainWindow.on("closed", () => {
    mainWindow = null;
  });
  mainWindow.removeMenu();
  mainWindow.loadFile(path.join(pluginRoot, "index.html"));
  return mainWindow;
}
```

### 2. 单实例和父进程监控

修改前：

```js
app.whenReady().then(() => {
  ...
  createWindow();
});
```

修改后：

```js
const hasSingleInstanceLock = app.requestSingleInstanceLock();

if (!hasSingleInstanceLock) {
  app.quit();
} else {
  app.on("second-instance", () => {
    createWindow();
  });

  app.whenReady().then(() => {
    ...
    startParentProcessMonitor();
    createWindow();
  });
}
```

### 3. 时间线分辨率读取

修改前：

```js
frameRate: Number.isFinite(frameRate) && frameRate > 0 ? frameRate : undefined,
timeline
```

修改后：

```js
frameRate: getTimelineFrameRate(timeline),
resolution: getTimelineResolution(timeline),
timeline
```

### 4. 导出面板按时间线回填

修改前：

```tsx
const selectedTimelineFrameRate = getPrimarySelectedTimelineFrameRate(timelines, selectedTimelineIds);
...
frameRate: selectedTimelineFrameRate
```

修改后：

```tsx
const selectedTimeline = getPrimarySelectedTimeline(timelines, selectedTimelineIds);
...
resolution: nextResolution,
frameRate: nextFrameRate
```

### 5. 时间线类型扩展

修改前：

```ts
frameRate?: number;
```

修改后：

```ts
frameRate?: number;
resolution?: ResolutionOption;
```
