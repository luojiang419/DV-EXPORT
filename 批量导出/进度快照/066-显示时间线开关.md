## 具体修改的代码前后对比

### 1. 操作参数持久化

修改前：

```ts
export interface PersistedExportSettings {
  hasManualPresetSelection: boolean;
  renderProfile: RenderProfile;
  outputDirectory: string;
  namingTemplate: string;
}
```

修改后：

```ts
export interface PersistedExportSettings {
  hasManualPresetSelection: boolean;
  showAllTimelines: boolean;
  renderProfile: RenderProfile;
  outputDirectory: string;
  namingTemplate: string;
}
```

### 2. 全部时间线读取能力

修改前：

```ts
getFolderTimelines(folderId: string): Promise<TimelineEntry[]>;
```

修改后：

```ts
getFolderTimelines(folderId: string): Promise<TimelineEntry[]>;
getAllTimelines(): Promise<TimelineEntry[]>;
```

### 3. 媒体池结构栏内容

修改前：

```tsx
<FolderTree tree={folderTree} selectedFolderId={selectedFolderId} onSelect={setSelectedFolderId} />
```

修改后：

```tsx
{showAllTimelines ? (
  <TimelineList
    emptyMessage="当前工程内没有可识别的时间线。"
    isLoading={isPreparingTimelineCache || isScanningTimelines}
    timelines={timelines}
    selectedIds={selectedTimelineIds}
    onSelect={handleTimelineSelect}
  />
) : (
  <FolderTree tree={folderTree} selectedFolderId={selectedFolderId} onSelect={setSelectedFolderId} />
)}
```
