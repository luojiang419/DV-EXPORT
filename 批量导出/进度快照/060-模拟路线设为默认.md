## 具体修改的代码前后对比

### 1. 前端默认选项

修改前：

```tsx
const [conversionStrategy, setConversionStrategy] = useState<FrameRateConversionStrategy>("resolve-render");
```

修改后：

```tsx
const [conversionStrategy, setConversionStrategy] = useState<FrameRateConversionStrategy>("resolve-ui-copy-paste");
```

### 2. 下拉框顺序

修改前：

```tsx
<option value="resolve-render">内部 API 复制</option>
<option value="resolve-ui-copy-paste">模拟手动复制粘贴（实验）</option>
```

修改后：

```tsx
<option value="resolve-ui-copy-paste">模拟手动复制粘贴（实验）</option>
<option value="resolve-render">内部 API 复制</option>
```

### 3. 核心默认策略

修改前：

```ts
export const defaultFrameRateConversionStrategy: FrameRateConversionStrategy = "resolve-render";
```

修改后：

```ts
export const defaultFrameRateConversionStrategy: FrameRateConversionStrategy = "resolve-ui-copy-paste";
```

### 4. 运行时默认兜底

修改前：

```js
return frameRateConversionStrategies.has(value) ? value : "resolve-render";
```

修改后：

```js
return frameRateConversionStrategies.has(value) ? value : defaultFrameRateConversionStrategy;
```
