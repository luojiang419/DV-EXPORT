## 具体修改的代码前后对比

### 1. 浏览器环境处理

修改前：

```ts
if (!window.resolveBridge) {
  throw new Error("插件 bridge 未注入");
}
```

修改后：

```ts
if (window.resolveBridge) {
  return window.resolveBridge;
}

if (import.meta.env.MODE === "demo") {
  demoBridge ??= createDemoResolveBridge();
  return demoBridge;
}

throw new Error("插件 bridge 未注入");
```

### 2. 官网统一构建

修改前：没有官网构建流程。

修改后：

```json
"build:website": "node ./scripts/build-website.mjs"
```

该脚本先构建 Web Demo，再构建官网，最后把 Demo 复制到官网产物的 `demo` 子目录并检查关键文件。

### 3. Web Demo 安全提示

修改前：普通浏览器无法打开插件界面。

修改后：演示模式载入模拟工程，并显示：

```text
安全演示模式
这里使用模拟工程数据……不会访问本机文件，也不会真正启动渲染。
```
