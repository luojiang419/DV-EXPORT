# 031 帧率转换标签页 UI

## 已完成内容

- 右侧操作面板新增标签页：
  - `导出设置`
  - `帧率转换`
- 新增 `FrameRateConversionPanel` 组件
- 帧率转换页显示：
  - 已选时间线数量
  - 目标帧率
  - 新媒体夹名称输入框
  - 当前选中时间线预览
  - 转换按钮
  - 转换结果汇总与逐条结果
- 转换按钮调用 `bridge.convertTimelineFrameRates`
- 转换成功后自动刷新媒体池树、时间线缓存和当前文件夹时间线列表
- 转换运行时会暂停右下角批量导出按钮
- 已执行验证：
  - `npm run typecheck`
  - `npm test`

修改前：

```text
文件不存在。
```

修改后：

```tsx
export function FrameRateConversionPanel({
  selectedTimelines,
  targetFrameRate,
  destinationFolderName,
  result,
  disabledReason,
  onConvert
}: FrameRateConversionPanelProps) {
  return (
    <div className="conversion-panel">
      <div className="conversion-panel__summary" />
      <input value={destinationFolderName} />
      <button disabled={Boolean(disabledReason)} onClick={onConvert}>
        转换所选时间线帧率
      </button>
      <FrameRateConversionResult result={result} />
    </div>
  );
}
```
