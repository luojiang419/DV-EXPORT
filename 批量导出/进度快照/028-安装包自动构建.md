## 具体修改的代码前后对比

### `package.json`

修改前：

```json
"build": "node ./scripts/build-plugin.mjs",
"test": "node ./node_modules/vitest/vitest.mjs run"
```

修改后：

```json
"build": "node ./scripts/build-plugin.mjs",
"build:installer": "node ./scripts/build-installer.mjs",
"test": "node ./node_modules/vitest/vitest.mjs run"
```

### `scripts/build-installer.mjs`

修改前：

```text
文件不存在。
```

修改后：

```js
const packageName = `DV-EXPORT-${versionTag}-windows-installer`;
const packageRoot = path.join(installerRoot, packageName);
const packagePluginDir = path.join(packageRoot, pluginFolderName);
const zipPath = path.join(installerRoot, `${packageName}.zip`);

cpSync(pluginDir, packagePluginDir, { recursive: true });
writeFileSync(path.join(packageRoot, "install-windows.ps1"), createPowerShellInstaller(version), "utf-8");
writeFileSync(path.join(packageRoot, "install-windows.bat"), createBatchInstaller(), "utf-8");
writeFileSync(path.join(packageRoot, "README.txt"), createReadme(version, packageName), "utf-8");
```

### `docs/部署文档.md`

修改前：

```powershell
$version = 'v0.1.12'
$pluginDir = "G:\data\app\DV-EXPORT\批量导出\dist\$version\com.dvexport.batch-export"
$package = "G:\data\app\DV-EXPORT\批量导出\dist\DV-EXPORT-$version-com.dvexport.batch-export.zip"
Compress-Archive -LiteralPath $pluginDir -DestinationPath $package -CompressionLevel Optimal
```

修改后：

```powershell
cd G:\data\app\DV-EXPORT\批量导出
npm run build:installer
```

### `docs/安装说明.md`

修改前：

```text
先构建插件目录，再手动复制 com.dvexport.batch-export 到 Resolve 插件目录。
```

修改后：

```text

```
