## 具体修改的代码前后对比

### 1. 帧率转换策略扩展

修改前：

```ts
export type FrameRateConversionStrategy = "resolve-render" | "ffmpeg-cfr" | "ffmpeg-motion";
```

修改后：

```ts
export type FrameRateConversionStrategy = "resolve-render" | "ffmpeg-cfr" | "ffmpeg-motion" | "resolve-ui-copy-paste";
```

### 2. 主进程新增 AutoHotkey 调用

修改前：

```js
ipcMain.handle("dv-batch-export:convert-frame-rate", async (_event, payload) => {
  return convertFrameRateWithFfmpeg(payload);
});
```

修改后：

```js
ipcMain.handle("dv-batch-export:run-resolve-timeline-automation", async (_event, payload) => {
  return runResolveTimelineAutomation(payload);
});
```

### 3. 运行时新增混合路线分支

修改前：

```js
const directCopyResult = copyTimelineContentsDirectly(...);
```

修改后：

```js
const directCopyResult =
  strategy === uiCopyPasteFrameRateConversionStrategy
    ? await copyTimelineContentsWithUiAutomation(...)
    : copyTimelineContentsDirectly(...);
```

### 4. UI 新增复制方式

新增：

```tsx
<option value="resolve-render">内部 API 复制</option>
<option value="resolve-ui-copy-paste">模拟手动复制粘贴（实验）</option>
```
